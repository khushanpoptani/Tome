# Tome

Tome is a macOS desktop client and a self-hosted Windows server for local AI conversations.

This repository contains the Phase 1 private-network server and durable job protocol, Phase 2 model management, and the Phase 3 macOS client foundation. The client now owns versioned local settings, named server profiles, one-file-per-chat storage, attachment/partial/export-cache foundations, offline chat lifecycle tools, and replay-aware server job history. Prompt inference, token streaming, attachment processing, and permanent server-side chat history remain outside Phase 3.
