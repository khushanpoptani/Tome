# Tome

Tome is a macOS desktop client and a self-hosted Windows server for local AI conversations.

This repository contains the Phase 1 private-network server, durable job protocol, Windows server dashboard/installer, and macOS connection bootstrap. Model and conversation features remain reserved for later, separately reviewed phases.
