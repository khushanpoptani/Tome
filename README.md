# Tome

Tome is a macOS desktop client and a self-hosted Windows server for local AI conversations.

This repository contains the Phase 1 private-network server and durable job protocol plus Phase 2 hardware discovery, verified model downloads, model registry/runtime lifecycle, Windows first-run model setup, and remote macOS model management. Chat persistence, inference, prompts, and attachments remain reserved for later, separately reviewed phases.
